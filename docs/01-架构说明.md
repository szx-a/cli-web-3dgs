# 01 · 架构说明

> 目标：**一套流程核心，两个入口（CLI / Web）**，任一入口的行为完全一致，
> 且每个阶段都能单独重跑、整个作业能断点续跑。

## 1. 分层

```
                        ┌──────────────────────────────────────────┐
                        │            流程核心 Pipeline              │
                        │  config / paths / events / pipeline /     │
                        │  stages / segment / trainers / tools      │
                        │  —— 不 import 任何 Web 或 CLI 模块         │
                        └───────────────┬──────────────┬───────────┘
                                        │              │
                          ┌─────────────▼───┐   ┌──────▼────────────────┐
                          │  CLI (cli.py)   │   │  Web (web/app.py)     │
                          │  argparse       │   │  FastAPI + SSE        │
                          │  控制台事件 sink │   │  事件总线 → 浏览器     │
                          └─────────────────┘   └───────────────────────┘
                                        │              │
                                        └──── 同一个 ───┘
                                   Orchestrator + JobSpec
```

**红线（代码评审时按这几条查）**

| # | 规则 | 原因 |
|---|---|---|
| 1 | `stages/`、`pipeline/`、`segment/`、`trainers/` 不得 import `web` 或 `cli` | 保证 GUI 换掉不影响流程 |
| 2 | 阶段之间不传内存对象，只传磁盘路径 + `job.json` | 关掉 GUI 明天接着跑 |
| 3 | 每个阶段声明 `inputs` / `outputs` | 编排器据此自动跳过已完成阶段 |
| 4 | 外部程序一律经 `tools/locate.py` + `tools/runner.py` | 缺工具时给“可执行的修复建议” |
| 5 | 凭据只走 `credentials.py`，永不写进 `config.toml` | 防误提交 |
| 6 | 任何 UI 动作都要能翻译成一条 CLI 命令 | 两端同构可验证 |

## 2. 模块地图

```
src/gsflow/
├─ paths.py            所有宿主路径与子进程环境（TEMP/缓存全部关进工作区）
├─ config.py           默认值 → config.toml → 运行时覆盖（点路径）
├─ credentials.py      API Key / HF Token / 镜像 / 代理
├─ errors.py           统一异常；ToolMissingError 带 advice
├─ events.py           EventBus + JSONL 落盘 + 控制台 sink
├─ imageops.py         掩码形态学、连通域、黑背景合成（纯 numpy/PIL）
├─ cli.py              gsflow 命令族
├─ pipeline/
│   ├─ base.py         Stage / Artifact / StageResult
│   ├─ context.py      StageContext（阶段能看到的受控世界）
│   ├─ registry.py     阶段注册与依赖闭包解析
│   └─ orchestrator.py JobSpec / Orchestrator / list_jobs
├─ stages/             frames → mask → colmap → train → export → metrics
├─ segment/            分割后端：base / fastsam / rembg / sam2 / sam3
├─ trainers/           训练后端：gsplat（默认）/ official / external
├─ gsdata/colmap_io.py COLMAP 二进制解析 + 去畸变数据准备
├─ tools/              locate（定位）/ runner（执行包装）/ doctor（自检）
└─ web/                FastAPI app + jobs 管理器 + static 前端
```

## 3. 阶段契约

| 阶段 | requires | 输入 | 输出 |
|---|---|---|---|
| `frames` | — | 视频 / 图片目录 | `01_images_raw/` |
| `mask` | frames | `01_images_raw/` | `02_masks/`、`02_images_clean/` |
| `colmap` | mask | `02_images_clean/`(+masks) | `03_colmap/sparse/0/*.bin`、`report.json` |
| `train` | colmap | `03_colmap/sparse/0`、清理图 | `04_train/point_cloud/iteration_N/point_cloud.ply` |
| `export` | train | PLY | `05_export/{model.glb, viewer.html, preview_*.png}` |
| `metrics` | train | 各阶段 metrics | `06_reports/report.md` |

阶段实现要点：

- **frames**：ffmpeg 抽帧（fps 或按目标张数）→ 长边缩放 → 可选清晰度剔除（梯度方差阈值）。
- **mask**：`segment.create(backend)` 拿到掩码 → 膨胀/羽化/连通域清理 → 黑背景（或补全）→ 掩码 PNG + 效果图 + manifest。
- **colmap**：feature_extractor → 匹配（按文件名自动判 sequential/exhaustive）→ mapper → model_converter(TXT) → 质量体检。mask_path 不支持时自动回退纯黑背景图。
- **train**：COLMAP `image_undistorter` 准备数据（用全白掩码避免掩码被几何变换）→ 原掩码按文件名映射到去畸变图 → gsplat 训练（渐进分辨率、自适应密度控制、掩码内损失、OOM 自动降档重试）。
- **export**：读 PLY（SH DC → RGB）→ GLB(POINTS)/OBJ/SPZ + 内嵌式离线查看器 + matplotlib 预览图。
- **metrics**：清晰度、掩码占比、相邻帧差异、注册率、PSNR 与改进建议 → markdown 报告。

## 4. 可扩展点

| 想加什么 | 改哪里 |
|---|---|
| 新的分割模型 | 实现 `segment/base.py:Segmenter`，在 `BACKENDS` 注册 |
| 新的训练器（LiteGS / faster-gaussian-splatting…） | 实现 `trainers/base.py` 协议，在 `pick()` 注册；或用 `train.backend=external` + `train.external_entry` |
| 新的阶段（如 inpaint、mesh 提取、4DGS） | 写 `Stage` 子类并在 `stages/__init__.py` 注册；CLI/GUI 自动出现 |
| 新的外部工具 | 在 `tools/locate.py` 的 `CANDIDATES` / `ADVICE` 加一项 |
| 大场景分块训练 | 新增阶段，复用现有 `train` 后端 |

## 5. 并发与资源

- 单卡串行：`runtime.max_parallel_jobs` 默认 1（两个作业同时抢 8GB 显存必 OOM）。
- 作业线程：`web/jobs.py` 用后台线程跑 `Orchestrator`，事件写进该作业的 `EventBus`；
  浏览器通过 `/api/run/{id}/stream`（SSE）实时消费。
- 取消：`threading.Event` 逐迭代检查，取消发生在迭代边界，已保存的检查点仍然可用。

## 6. 产物与别名

- 作业目录：`workspace/<job_id>/`（真实路径 `F:\3dgs-and-ai\workspace`）。
- `D:\3dgs-workspace\workspace\<job_id>` 是它的目录链接，方便在 D 盘查看。
- 每个作业的 `job.json` 是唯一状态源：参数快照、阶段状态、产物路径。
