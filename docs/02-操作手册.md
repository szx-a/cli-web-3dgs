# 02 · 操作手册

> 所有命令都在 `F:\3dgs-and-ai`（或 `D:\3dgs-workspace`，同一份目录）下执行。
> CLI 统一用 `scripts\gsflow.cmd`，它自动使用工作区虚拟环境。

---

## 0. 一次性准备

```bat
:: 建虚拟环境 + 核心依赖（约 2 分钟）
powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1

:: 装 GPU 依赖：torch(cu128) + gsplat（torch 约 2.6GB）
powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1 -Gpu

:: 装分割后端（FastSAM / rembg）
powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1 -Segment

:: 自带外部工具（免安装、可断点续传）
scripts\download.cmd colmap
scripts\download.cmd ffmpeg
```

CUDA Toolkit（gsplat 编译内核必需，约 3.3GB）：

```bat
scripts\download.cmd cuda
:: 下载完成后，右键“以管理员身份运行 PowerShell”：
powershell -ExecutionPolicy Bypass -File scripts\install_cuda.ps1
```

装完检查：

```bat
scripts\gsflow.cmd doctor
```

`doctor` 会打印：软硬件、磁盘、外部工具、Python 依赖、网络连通性，最后是**待办清单**
（`!! 阻断` / `! 注意` / 提示）。阻断项清零就可以开跑。

## 1. 跑一个作业（CLI）

```bat
:: 视频输入：抽帧 → 分割清理 → COLMAP
scripts\gsflow.cmd run --video D:\data\room.mp4 --stages frames,mask,colmap

:: 图片输入：直接清理 + 重建（默认全部阶段）
scripts\gsflow.cmd run --images D:\data\photos

:: 只跑清理，看看掩码质量
scripts\gsflow.cmd run --images D:\data\photos --stages frames,mask

:: 大场景：降低训练分辨率、减少迭代
scripts\gsflow.cmd run --images D:\data\city --set train.resolution=1200 --set train.iterations=15000

:: 分割后端换成 rembg，并给提示词
scripts\gsflow.cmd run --images D:\data\obj --set mask.backend=rembg
scripts\gsflow.cmd run --images D:\data\street --set mask.backend=fastsam --set mask.prompt=car
```

常用子命令：

| 命令 | 作用 |
|---|---|
| `gsflow doctor [--json] [--save]` | 环境自检；`--save` 写入 `docs/env-report.json` |
| `gsflow stages` | 列出阶段与输入输出 |
| `gsflow run ...` | 执行作业 |
| `gsflow jobs [--json]` | 列出历史作业 |
| `gsflow status <job_id>` | 看某作业各阶段状态 |
| `gsflow export <job_id>` | 只重跑导出阶段 |
| `gsflow creds --show` / `--set hf_token=xxx` | 凭据管理 |
| `gsflow web --port 8787 --open` | 启动 Web GUI |

### 断点续跑 / 单阶段重跑

```bat
:: 同一个 job_id 再跑一次：已有产物的阶段自动跳过
scripts\gsflow.cmd run --images D:\data\photos --job-id 20261002-120000-ab12cd

:: 强制重跑某个阶段（例如掩码调参后）
scripts\gsflow.cmd run --job-id 20261002-120000-ab12cd --stages mask,colmap,train --force mask,colmap,train
```

## 2. 跑一个作业（Web GUI）

```bat
scripts\web.cmd            :: 等价于 gsflow web --open
```

> ⚠️ **改代码后何时需要重启**（踩过：界面看起来是新的，接口却 404）
> | 改了什么 | 怎么做 |
> |---|---|
> | `src/gsflow/web/static/*`（前端）| **Ctrl+F5** 刷新即可（静态文件每次从磁盘读）|
> | `src/gsflow/web/app.py`（后端/新接口）| **必须重启服务**（uvicorn 不热重载）|
> | `src/gsflow/` 其它模块 | 同样需要重启（进程里是旧模块）|
>
> 自查命令：`python scripts\check_server_code_sync.py`
> —— 它会比对"代码里定义的路由"与"运行中服务实际暴露的路由"，
> 并区分 **404（路由不存在 = 服务旧）** 与 **405（方法不允许 = 路由存在）**。

浏览器打开 `http://127.0.0.1:8787`：

1. **新建作业**：填输入路径 → 勾阶段 → 调关键参数 → 点「开始重建」。
   右下角实时显示**等价的 CLI 命令**，可直接复制到终端。
2. **作业与进度**：实时日志、进度条、取消按钮；点历史作业可回看日志与产物链接。
3. **环境自检**：等同于 `gsflow doctor`，上方是待办清单。
4. **设置 / API Key**：
   - HuggingFace Token、HF 镜像（`https://hf-mirror.com`）、代理、SAM3 API Key；
   - 分割/训练/导出/COLMAP 的流程配置（点路径编辑），保存即写 `config/config.toml`；
   - 外部工具路径（留空自动探测）。

### 2.1 模型页的五个模式（**高斯是独立渲染路径**）

| 模式 | 显示什么 | 什么时候用 |
|---|---|---|
| `preview`（默认）| 服务端 gsplat 渲的 `preview_*.png` | **最可靠**：不用 WebGL，任何驱动/机器都能看到真实外观 |
| `splat` | `model_gaussians.ply`（59 维含 SH），由**社区参考实现**渲染 | 想看交互式 3D 高斯（可旋转/缩放）|
| `points` | `model.glb` 点云 | 看几何分布 |
| `mesh` | `model_mesh.glb / .ply` 网格 | 看提取出的表面 |
| `textured` | `model_mesh_textured.glb` | 看贴图效果 |

- 高斯用 `refviewer.js`（vendored `@mkkellogg/gaussian-splats-3d`）；网格/点云用自带的
  WebGL1 查看器。**两者互不干扰**：切换模式时会先撤掉另一路的图层。
- 「**服务端渲染当前视角**」按钮：把你在查看器里转到的相机，交给服务端用 gsplat
  渲一张 PNG 出来（`/api/render/{job}?yaw=…&pitch=…&dist=…`）。
  **当查看器和预期不一致时，先点这个** —— 它用的渲染器和训练/预览完全一致，
  可以把"模型问题"和"浏览器渲染问题"分开（03/G122）。
- 「**回到 WebGL 交互**」：从服务端 PNG 切回可交互视图。
- 打不开时的第一站：`/api/selftest?job=<job_id>`，它一次列出
  静态脚本是否可访问、产物清单里哪些路径缺失、参考渲染器是否可用。

> GUI 与 CLI 是同一套逻辑：GUI 提交的作业，`gsflow jobs` 里能看到；CLI 建的作业，GUI 里也能看进度。

## 3. 输入怎么拍

| 要点 | 建议 |
|---|---|
| 重叠 | 相邻视角重叠 ≥ 70%，环绕时每步转动小一点 |
| 数量 | 小物体 60~120 张；房间 150~300 张；建筑外景 300~600 张 |
| 光照 | 避免运动模糊与曝光跳变；视频抽帧时 fps 取 2~4 |
| 纹理 | 纯色墙面/玻璃/镜面会导致 COLMAP 注册失败，尽量补纹理 |
| 动态物体 | 行人车辆用掩码屏蔽（本流程默认输出掩码） |

## 4. 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `frames.mode` | fps | `fps` 定帧率 / `count` 按目标张数均匀抽 |
| `frames.long_side` | 1920 | 图片长边；>`0` 时缩放 |
| `frames.blur_threshold` | 0 | >0 时用梯度方差剔除模糊帧（0 关闭） |
| `capture.mode` | auto | `auto` 按帧间差异判定 `turntable`/`orbit`；判定结果会写进日志 |
| `mask.backend` | fastsam | `fastsam` / `rembg` / `sam2` / `sam3` |
| `mask.mode` | black | `black` 背景填黑 / `keep` **保留背景**（turntable 自动选它，否则 COLMAP 特征不足）/ `inpaint` |
| `mask.dilate_px` / `feather_px` | 4 / 2 | 掩码外扩与羽化，抑制边缘黑边 |
| `colmap.matcher` | auto | 按文件名自动判 sequential / exhaustive |
| `colmap.max_image_size` | 2048 | 特征提取的图像上限 |
| `colmap.use_masks` | true | 支持时启用 mask_path，否则自动回退 |
| `train.backend` | gsplat | `gsplat` / `official` / `external` |
| `train.iterations` | 30000 | 迭代次数；8GB 卡建议 15000~30000 |
| `train.resolution` | 1600 | 训练分辨率长边；OOM 会自动降档（**只缩小不放大**）|
| `train.cap_max` | 1500000 | 高斯数量上限（显存守护）|
| `train.densify_criterion` | grad2d | `grad2d`（官方语义，**同等质量省 ~48% 高斯**）/ `grad3d` |
| `train.max_scale_ratio` | **0.05** | **每步**钳制高斯尺度 ≤ `ratio × 场景尺度`。关掉它，致密化窗口之后尺度无约束，会出现 15.8 米长的"针"（模型只有 4 米）⇒ 自由视角细丝、网格皱成一团（`docs/03` G125）|
| `train.bg_alpha_reg` | **0.1** | 掩码外 **alpha** 惩罚。没有它，模型会用不透明黑高斯填满背景（掩码外 alpha 0.73）⇒ 转到侧面看到"黑壳/背面混乱"|
| `train.mask_loss_mode` | composite | 掩码外合成背景色后全图算损失。**改了要验证** `psnr_masked` 明显高于 `psnr` |
| `train.mask_loss_until` | 1.0 | 掩码损失生效的迭代占比（1.0 = 全程）|
| `export.formats` | glb_points, viewer_html | 另有 `mesh`、`splat`、`ply_full`、`viewer_splat`、`obj`、`spz`（需 `pip install spz`）|
| `export.mesh_crop_quantile` | 1.0 | 网格聚焦的分位数裁剪。**1.0 = 只用 `mesh_crop_opacity` 过滤，不按分位数裁** —— 分位数会先裁掉稀疏但真实的屋檐/翼角（03/G119）|
| `export.mesh_crop_opacity` | 0.05 | 建网格时丢弃低于该不透明度的点（背景污染靠它）|
| `export.auto_crop` | true | 帧阶段的时间方差自动裁剪（必须在 COLMAP 之前）|

> 完整参数表见 `README.md`；两边由 `scripts\check_docs_consistency.py` 强制校验。

## 5. 产物在哪

```
workspace\<job_id>\
├─ job.json                       参数快照 + 阶段状态（唯一状态源）
├─ logs\events.jsonl             全部事件（GUI/CLI 共用）
├─ logs\colmap.log 等             外部工具原始输出
├─ 01_images_raw\                 抽帧/导入结果
├─ 02_masks\                      掩码 + _overlay\ 效果图 + manifest.json
├─ 02_images_clean\               ★ 清理图（COLMAP 的输入）
├─ 03_colmap\{database.db, sparse\, sparse_txt\, report.json}
├─ 04_train\data\                 去畸变训练数据（images/ + masks/ + sparse/）
├─ 04_train\point_cloud\iteration_30000\point_cloud.ply   ★ 最终模型（59 维）
├─ 05_export\
│   ├─ model_gaussians.ply        ★ 完整 59 维高斯（含 SH），高斯查看用这个
│   ├─ model.splat                32 字节/高斯的紧凑格式（体积约 1/8）
│   ├─ model_mesh.ply/.glb/.obj   三角网格
│   ├─ model_mesh_textured.glb    带贴图网格
│   ├─ viewer_splat.html + vendor\  离线高斯查看器（双击即看，不需服务）
│   ├─ model.glb                  点云 glTF
│   ├─ preview_*.png              服务端 gsplat 渲染的预览图
│   └─ manifest.json              产物清单（含类型判定：gauss3d / mesh / image）
└─ 06_reports\report.md           质量报告与改进建议
```

**怎么查看**：

| 想看什么 | 用什么 |
|---|---|
| 最稳、最接近训练时外观 | `preview_*.png`（服务端渲染）|
| 交互式 3D 高斯 | Web GUI 的 `splat` 模式，或双击 `viewer_splat.html` |
| 网格/贴图 | Web GUI 的 `mesh` / `textured` 模式，或拖进任意 glTF 查看器 |
| 拿到别的工具里用 | `model_gaussians.ply`（通用 3DGS 格式）或 `model.splat` |

### 5.1 质量数字怎么看（**别再看全图 PSNR**）

掩码生效后，训练会把**掩码外压成背景色**，所以全图指标天然很低且不代表画质：

| 指标 | 全图 | **掩码内** | 用哪个 |
|---|---|---|---|
| PSNR | 3.41 dB | **20.47 dB** | 掩码内 |
| SSIM | 0.367 | **0.946** | 掩码内 |

- 位置：`04_train/metrics.json` 的 `psnr` / **`psnr_masked`** / `ssim` / **`ssim_masked`**。
- **自查**：`psnr_masked - psnr` 应 > 3 dB；接近就说明掩码没生效（03/G123）。
- `psnr_masked` 目前没有社区基准，`final_acceptance.py` 用 18 dB 作**回归守门**
  （标注"阈值待标定"），主判据是**掩码内 SSIM ≥ 0.93**。

## 6. 典型工作流

**A. 视频 → 3DGS**

```bat
scripts\gsflow.cmd run --video D:\data\room.mp4 --set frames.fps=3 --set frames.long_side=1600
```

**B. 只看清理效果（快速迭代掩码参数）**

```bat
scripts\gsflow.cmd run --images D:\data\photos --stages frames,mask --force mask
:: 打开 workspace\<job_id>\02_masks\_overlay\ 抽检边缘
```

**C. 已有 COLMAP 结果，只想训练**

```bat
:: 把 COLMAP 结果按 03_colmap\sparse\0\ 放好，然后：
scripts\gsflow.cmd run --job-id my-job --stages train,export --force train
```

**D. OOM**

```bat
scripts\gsflow.cmd run --job-id my-job --stages train --force train --set train.resolution=1000 --set train.cap_max=800000
```
