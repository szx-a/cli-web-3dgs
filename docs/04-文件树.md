## 模块职责

| 模块 | 职责 | 关键约束 |
|---|---|---|
| `pipeline/` | 阶段注册、编排、事件总线、作业状态 | **不依赖 UI**；阶段间只通过磁盘产物 + `job.json` 通信 |
| `stages/` | frames → mask → colmap → train → export → metrics | 每个阶段可单独重跑，产物落 `0N_*` 目录 |
| `trainers/` | 训练后端（gsplat 默认 / official / external） | 实现 `base.py` 协议即可插拔 |
| `gsdata/` | COLMAP 读写、深度反投影、泊松/TSDF 网格提取 | 纯几何，不依赖训练栈 |
| `segment/` | 分割后端（rembg/classical/FastSAM/SAM2/SAM3） | 实现 `Segmenter` 协议 |
| `web/` | FastAPI + 静态前端 | 与 CLI **共用同一 Orchestrator**（同构红线） |
| `web/static/refviewer.js` | 高斯显示的**适配层** | 渲染像素交给 vendored `gaussian-splats-3d`，本文件不含任何着色器代码（`docs/03` G116/G121）|
| `web/static/viewer.js` | WebGL1 查看器：glb / **普通** ply（网格、点云）| 遇到 3DGS PLY 或 `.splat` **明确报错**并指向 refviewer |
| `web/static/splat.legacy.js` | 已下线的自研泼溅器（归档）| **不被 index.html 加载**；保留仅供追溯 |
| `cli.py` | 命令行入口 | 与 GUI 等价，GUI 会打印等价 CLI 命令 |
