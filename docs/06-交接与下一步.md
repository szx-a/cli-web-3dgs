## 2. 下一步做什么（按优先级）

### ✅ 已完成（2026-10-22，见 `docs/03` G125）

| 问题 | 根因 | 修法 | 结果 |
|---|---|---|---|
| 自由视角**细丝化** | 尺度在致密化窗口后无约束，长到 15.8 米（模型 4.16 米）；`aniso>100` 占视觉权重 94.8% | `train.max_scale_ratio=0.05`（每步钳制） | `max_scale` **0.165**、针状权重 **23.5%** |
| **背面混乱 / 黑壳** | 掩码只把背景"染黑"，没删几何：掩码外 alpha 0.70 | `train.bg_alpha_reg=0.1`（掩码外 alpha 惩罚） | 掩码外 alpha **0.0493** |
| 网格"乱作一团" | 针状云跑泊松 | 随上两项一起消失 | 边界边 **23.9% → 8.8%**、面积/凸包 **0.46**（无褶皱）|

### ① 贴图图集有明显伪影（下一个最值得做的）

`05_export/model_mesh_texture.png`（2048²）目视可见：**大片斑块噪声** +
**一处亮绿色块**（UV 接缝/采样越界）。这会让带贴图网格看起来"脏"。
候选：抬高 `export.mesh_texture_size`、加 UV 接缝填充（dilate）、
在重采样时排除绿色异常值。

### ② 网格的"自相交"仍未消除

`mesh_quality.py` 报告 `自相交 True`（泊松常态）。目前用**面积/凸包**判褶皱（0.46 正常），
但如果用户仍觉得网格乱，下一步应做**自相交面片计数**（open3d 无现成 API，
可用射线法：每面片中心沿法向打一条射线，统计命中自身其它面片的次数）。

### ③ 分辨率的天花板

训练分辨率是素材裁剪后的 **456×290**（原图 577×1309，物体在画面中占比小）。
这是当前画质的主要上限。若素材允许，**拍得更近 / 用更长焦**比调参更有效。

## 2b. 历史待办：容量集中度（已部分缓解）

`n80`（贡献 80% 视觉权重的比例）从 1.6% 升到 8.6%，但仍是"少数高斯画大部分画面"。
已通过 `max_scale_ratio` 缓解；如继续优化，候选项与判据见下表：

| 方案 | 配置 | 预期 |
|---|---|---|
| 尺度正则 | `train.scale_reg`（默认 0） | 压住膨胀 |
| 更严的尺度上限 | `max_scale_ratio=0.03` | 进一步限长 |
| 不透明度-面积联合剪枝 | 需新写 | 针对"大而淡" |

**验收判据**（三条都要看）：掩码内 SSIM ≥0.93 不掉；`max scale` 下降；
`check_free_view.py` 的**掩码外 alpha** 不回升。

### ② 给掩码内 PSNR 找"合理区间"（现在只有回归守门）

`final_acceptance.py` 里掩码内 PSNR 阈值是 **18 dB**，标注"**阈值待标定**"，
因为掩码内口径没有社区基准。第一个实测值是 20.47 dB。

要做的事：在**另一份素材**上跑一遍完整流程，看掩码内 PSNR 与 SSIM 的落点，
据此把阈值从"回归守门"升级为"质量线"。**注意**：换素材要重跑 COLMAP，
不能拿不同素材的数字直接比（见 `docs/01` 实验纪律 #1）。

## 4. 出问题时的第一站

| 症状 | 先做什么 |
|---|---|
| GUI 里打不开模型 | 打开 `/api/selftest?job=<id>`，它一次列出静态脚本/产物路径/参考渲染器状态 |
| 查看器效果和预期不符 | 点「**服务端渲染当前视角**」，用 gsplat 渲同一相机 —— 能分清"模型问题"还是"浏览器问题" |
| 怀疑某个配置没生效 | `python scripts\check_train_used_config.py --job <id>`（看**实际**用的判据/损失口径）|
| 怀疑掩码没生效 | `python scripts\diag_alpha_background.py --job <id>`：掩码外亮度应 ≈0，且 `psnr_masked - psnr > 3 dB` |
| 网格看起来是碎片 | `python scripts\diag_gauss_weight.py --job <id>`：看导出网格覆盖了多少**视觉权重** |
| 亮暗异常/发白 | `diag_bright_background.py` + `diag_bright_shell.py`（看亮高斯占视觉权重与半径分布）|
| gsplat 报 JIT 编译/解码错 | 别调 `render_view`；先看 `sys.modules['gsplat.csrc']`，判据见 `docs/03` G123 附注 |

## 6. 判据红线（动质量相关代码前必读）

1. **质量看掩码内指标**；全图 PSNR/SSIM 在掩码生效后**必然失效**。
2. **配了不等于生效**：改判据/损失口径后必须查"实际生效值"，并配一条**症状守门**
   （例：`psnr_masked - psnr > 3 dB`）。
3. **改一个中间量就要重算下游**：两次最贵的 bug 都是"用了变量的旧快照"（G109、G123）。
4. **指标从产生它的那一层取**，不要拿渲染/合成后的产物反推（G122）。
5. **一次实测不下结论**：同配置噪声底 0.03~0.05 dB，判断差异要 95% CI（G79）。
6. **检查器必须有负向测试**，否则是恒过的装饰（G87、G88）。
7. **不要退回降级方案**（如点云替代高斯）：那是妥协，会把问题藏起来。
