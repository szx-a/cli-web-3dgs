# 07 · 安装与部署

本文只讲**怎么把 gsflow 装到一台 Windows 机器上并跑起来**。
算法与参数见 [`05-训练框架.md`](05-训练框架.md)，操作命令见 [`02-操作手册.md`](02-操作手册.md)。

---

## 0. 两条路径，选一条

| 方式 | 适用 | 命令 |
|---|---|---|
| **可视化安装器**（推荐）| 新机器、给同事装、需要选路径/组件 | `python installer\gsflow_installer.py` |
| 脚本 | 服务器、CI、无人值守 | `powershell -ExecutionPolicy Bypass -File scripts\bootstrap.ps1 -All` |

两者做的事**完全一样**（安装器只是把 bootstrap 的步骤编排成界面）：

```
1. 复制项目本体  →  2. 建 venv（uv）  →  3. 装依赖（core / gpu / segment）
4. 挂载 src（.pth） →  5. 下载外部工具与权重  →  6. gsflow doctor 验收
```

---

## 1. 前置条件

| 项 | 要求 | 检查方式 |
|---|---|---|
| 操作系统 | Windows 10/11 x64 | — |
| Python | **≥ 3.10**（本机 3.13.11）| `python --version` |
| uv | 建议安装（安装器会自动装）| `uv --version` |
| GPU（可选）| NVIDIA，**计算能力 sm_120 需 CUDA ≥12.8** | `nvidia-smi` |
| 磁盘 | core 8 GB；含 GPU + 工具 **≥20 GB** | 安装器会检测 |
| 网络 | 首次安装需下载依赖/工具/权重（数 GB）| — |

> **没有 GPU 也能装**：`--components core` 只装 CPU 侧依赖（抽帧、掩码、COLMAP 调度、导出、GUI 都能用），
> 训练需要 GPU 时再补 `gpu` 组件。

---

## 2. 可视化安装器

```bat
python installer\gsflow_installer.py
```

三页向导：

1. **环境检测** —— Python / uv / Tkinter / GPU / 磁盘 / 目标目录写权限，逐项 ✅ 或 ⚠️；
2. **路径与组件** —— 安装路径（默认 `F:\3dgs-flow`，可浏览选择）、组件勾选、
   可选"**复用已有安装**"（填现有安装目录，会复制 `env/uv-cache`、`env/pip-cache`、`models/`、`tools/`，
   省数 GB 流量与十几分钟）；
3. **安装** —— 实时日志 + 进度条；结束后弹窗提示，失败会保留日志。

### 组件

| 组件 | 内容 | 体积 |
|---|---|---|
| `core`（必选）| numpy / pillow / plyfile / fastapi / uvicorn / scipy / matplotlib | ~100 MB |
| `gpu` | torch(cu128) + gsplat | ~2.6 GB |
| `segment` | rembg + ultralytics + onnxruntime 等 | ~300 MB |
| `tools` | COLMAP 4.2.1 + FFmpeg | ~900 MB |
| `weights` | VGG16（LPIPS）、FastSAM | ~200 MB |

### 无人值守

```bat
python installer\gsflow_installer.py --silent --path F:\gsflow ^
    --components core,gpu,tools,weights --reuse-from F:\3dgs-and-ai

python installer\gsflow_installer.py --check-only     :: 只检测，不装
python installer\gsflow_installer.py --silent --path X --components core --dry-run
```

## 3. 装完怎么用

```bat
cd /d <安装目录>

scripts\gsflow.cmd doctor                          :: 环境自检（应全绿）
scripts\gsflow.cmd run --video data\x.mp4 --stages frames,mask,colmap,train,export
scripts\web.cmd                                    :: Web GUI → http://127.0.0.1:8787
```

安装器会在安装目录里放好 `config/config.toml`（含默认值）与 `workspace/` 等目录；
**配置里的 `workspace_dir` 指向该安装目录**，因此整个目录可以直接打包搬走。

---

## 4. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `doctor` 里 CUDA 不可用 | 装的是 CPU 版 torch | 重跑安装器勾 `gpu`，或 `uv pip install --index-url .../cu128 torch torchvision` |
| `sm_120` 内核缺失 | torch < 2.7 | 必须用 cu128 且 ≥2.7 的轮子 |
| venv 创建失败 | 系统 Python 缺 venv/权限 | 用安装器（它用 uv 建），或指定 `--python D:\python\python.exe` |
| 下载卡住 | 网络 | 勾"复用已有安装"，或先手动下好放 `tools/`、`models/` |
| `pip install -e .` 报 `WinError 5` | 本机 PEP517 构建受限 | **不要**用 editable 安装；安装器已用 `.pth` 挂载 |
| GUI 打开是白屏 | 浏览器缓存旧脚本 | Ctrl+F5 |
| 训练 OOM（8 GB 卡）| 分辨率/高斯数过高 | `--set train.resolution=1400 --set train.cap_max=400000` |

---

## 5. 卸载

删除安装目录即可（安装器不写注册表、不装系统服务）。
如果要保留模型产物，先备份 `workspace\` 目录。

## 6. 真机实测记录（2026-10-25，`F:\3dgs-flow`）

| 步 | 结果 |
|---|---|
| 复制项目本体 → `uv venv` | ✔ |
| 直接装 core 依赖 | ✘ `error sending request for url`（网络抖动）|
| 加 `--reuse-from F:\3dgs-and-ai` 重试 | ✔ 复用 uv/pip 缓存与 `models/`、`tools/`，**38 个包 0.4 秒装完** |
| 重写本机配置（`gsflow init --force`）| ✔ 输出"配置已指向安装目录" |
| `doctor --json` / `--help` | ✔ |
| 冒烟作业（抽帧）| ✔ 自动裁边 864x1920→864x644 + 抽帧 34 张 + 作业 done |
| 清理 | ✔ 删除 7.7 GB，目录保留为空 |

**两个教训**：

1. **必须重写配置**：安装器会把项目本体（含 `config/config.toml`）复制过去，而那是"本机配置"。
   第一版装完后 `workspace_dir` 仍指向源安装 —— 用户一跑作业就写到别的目录。现在安装器在挂载 `src` 后
   执行 `gsflow init --force` 并校验结果（`tests/test_installer_contract.py` 会拦住删掉这一步的改动）。
2. **`--reuse-from` 是刚需**：网络不稳时它是"能不能装上"的区别，不只是快慢。

## 7. GPU 组件实测（2026-10-25，env\\install-gpu）

| 检查 | 结果 |
|---|---|
| 安装 core,gpu（--reuse-from）| ✔ torch 2.11.0+cu128、torchvision 0.26.0+cu128、gsplat 1.5.3 |
| 依赖耗时 | **1.6 秒**（缓存命中；纯下载约 2.6 GB）|
| doctor | ✔ 	orch cuda_build=12.8 可用=True sm_120 内核支持=True |
| 配置 | ✔ 自动指向安装目录 |
| 清理 | ✔ 6.4 GB 测试产物已删除 |

**缓存复用又改成了"直接指向"**：第一版把 env/uv-cache **复制**到新安装，结果
copytree 撞上缓存里的 .tmp* 临时目录（WinError 5）而中断，半截缓存反而让安装继续联网并失败。
现在不复制缓存，而是把 UV_CACHE_DIR / PIP_CACHE_DIR **直接指向源安装**；
只复制 models/ 与 	ools/ 这类纯数据目录。另加了依赖安装 3 次重试（本机网络会间歇性
error sending request for url）。
