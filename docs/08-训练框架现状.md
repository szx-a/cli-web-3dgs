# 训练框架现状（2026-10-30）

> 这份文档回答三个问题：**现在的训练框架长什么样**、**参数都改了什么**、**凭什么这么改**。
> 每个结论后面都标了实测记录编号（`docs/03` 的 Gxxx），可以直接回溯到数据。

## 1. 流水线与后端

```
抽帧 → 掩码/背景清理 → COLMAP(位姿) → 3DGS 训练(gsplat) → 导出(glb/splat/网格/贴图/查看器)
```

* **流程核心**：`src/gsflow/pipeline` + `src/gsflow/stages`，不依赖任何 UI；
  CLI（`gsflow run`）与 Web GUI 只是两个入口，参数最终都拍平成同一份 `Settings`。
* **训练后端**：默认 `train.backend=gsplat`（gsplat 1.5.3 + torch 2.11.0+cu128，适配 RTX 5060 的 sm_120）。
  另有 2DGS 实验后端，仅用于对照，不作为默认。
* **阶段可续跑**：每个阶段只读写磁盘产物 + `job.json`；`--force train,export` 可只重跑训练与导出。

## 2. 训练框架（gsplat）

### 2.1 前向

$$\alpha\text{-合成：}\quad C(u)=\sum_j \alpha_jT_jc_j,\qquad
D(u)=\frac{\sum_j\alpha_jT_jz_j}{\sum_j\alpha_jT_j},\qquad
T_j=\prod_{k\lt j}(1-\alpha_k)$$

$D(u)$ 是**期望深度（ED）**，训练侧的法线/失真与导出侧的反投影**统一用它**（G153）。
`render_mode="D"` 给的是未归一化的 $\sum w z$，两者差 $1/\sum w$ 倍，混用会让法线偏 26°。

### 2.2 损失组成（默认值，2026-10-30）

| 项 | 键 | 默认 | 生效条件 | 证据 |
|---|---|---|---|---|
| 颜色 L1 + SSIM | `ssim_weight` | 0.2 | 始终 | — |
| 高阶 SH L2 | `sh_rest_reg` | 0.003 | 始终 | 治"斜视彩虹" |
| 不透明度对称正则 | `opacity_crisp_reg` / `_warmup` | 0.02 / 0.7 | 始终（退火）| G158 |
| **不透明度单边下限** | `opacity_floor` / `_reg` / `_warmup` | **0.10 / 0.5 / 0.5** | 始终 | G158/G159 |
| **深度方差（治朦胧）** | `lambda_depth_var` / `_warmup` | **1.0 / 0.3** | 始终 | G162/G165 |
| 感知损失 LPIPS | `lambda_lpips` / `lpips_every` | 0（预设开 0.05）| 开启后**每步** | G152/G164 |
| 细节梯度损失 | `lambda_grad` / `grad_warmup` | **0.3** / 0.2（`solid` 1.0）| 始终 | G166 |
| 法线一致性 | `lambda_normal` | 0（预设 0.02）| 仅 2DGS 面元路径 | G155 |
| 深度失真（TV 代理） | `lambda_depth_distortion` | 0（预设 0.02）| 同上 | — |
| 掩码外 alpha 抑制 | `bg_alpha_reg` | 0.1 | 掩码内损失模式 | G150 |

### 2.3 自适应密度控制（`densify_strategy=builtin`）

* 窗口：`densify_from=500` → `densify_until=4000`（预设延到 10000），每 `densify_interval=100` 步一次；
* 判据：屏幕空间梯度 $g_j=\|\partial\mathcal{L}/\partial\mu_j^{2D}\|$，
  阈值 `densify_grad2d_threshold=2e-4`；克隆/分裂后受 `cap_max` 约束；
* 剪枝：$\alpha_j<$ `prune_opacity=0.005`，或尺度 $>$ `prune_scale3d=0.1 \times scene\_scale$；
* 尺度上限：`max_scale_ratio=0.05`、`max_aspect=50`（防"针状"发散）；
* 重置：`opacity_reset_interval=0`（默认不重置；预设 3000），重置目标
  $\rho=\max(\texttt{reset\_opacity}, 2\varepsilon_\alpha)$，且 `auto_extend_densify_when_reset=true` 会顺延窗口。

> `densify_strategy=official`（gsplat `DefaultStrategy`）**仍不推荐**：我们补上了漏传的 `cap_max`，
> 但阈值在真实数据上会涨到 251 万高斯（G157），要重新标定后才能用。

### 2.4 优化器与学习率

| 项 | 默认 | 说明 |
|---|---|---|
| `lr_means_scene_scale` | false | means 学习率 $1.6\times10^{-4}$（不乘场景尺度）|
| `lr_shs` | 0.0025 | 高阶 SH |
| `lr_opacities` | 0.025 | 不透明度 logit |
| `lr_quats` | 0.001 | 四元数 |
| `lr_schedule` / `lr_min_ratio` | cosine / 0.1 | $\eta(t)=\eta_{\min}+(\eta_0-\eta_{\min})\frac12(1+\cos\frac{\pi t}{T})$ |

## 3. 参数改变（2026-10-25 → 10-30）

| 日期 | 改动 | 从 → 到 | 依据 |
|---|---|---|---|
| 10-25 | 深度语义统一 | `Σwz` → **ED** | 法线偏 26°，G153 |
| 10-25 | 官方密度控制 | 补 `cap_max` 传参 | 251 万高斯，G157 |
| 10-26 | **不透明度下限默认开启** | 0 → **0.10**（权重 0.5）| `op<0.1` 85%→4%，PSNR +0.01、SSIM +0.0003 |
| 10-26 | 新增 `solid` 预设 | — → 60k/cap400k/下限 | 双赢：PSNR 30.56、实心度 3.1× |
| 10-30 | **深度方差正则默认开启** | 0 → **1.0** | 15k：方差 −60%、p90 −81%、代价噪声级；60k：方差 −87%，LPIPS +0.0046 |
| 10-30 | LPIPS 权重 | 0.10 → **0.05** | 30k 四臂标定：λ 不敏感，0.10 只让高斯数 +21% |
| 10-30 | **细节梯度损失默认开启** | 0 → **0.3**（`solid` 1.0）| 15k：PSNR +2.0 dB、LPIPS −0.016；λ=1.0 时 +4.7 dB、−0.037，G166 |

## 6. 验收口径（不要只看 PSNR）

| 指标 | 工具 | 阈值 |
|---|---|---|
| 掩码内 PSNR/SSIM | `check_quality_suite` / `probe_lpips_new` | 黑底模式唯一有意义 |
| LPIPS（论文对齐） | `probe_lpips_new` | 越低越好，必须同一实现 |
| 实心度 | `check_gaussian_solidity` | `op` 中位 ≥0.1、`op<0.1` <30% |
| 深度方差 | `probe_depth_variance` | 越小越"实"（不是越小越好，看目标）|
| 质感（梯度/高频能量比）| `probe_texture_quality` | 梯度能量比 0.9~1.15，高频相关越高越好 |
| 白边/彩度 | `check_rim_brightness` / `render_orbit_sheet` | rim <0.10、彩度 <0.12 |
| 网格封闭 | `check_mesh_quality` | 边界边 0、非流形 0 |

## 7. 已知限制

1. **网格仍是弱项**：薄/空心结构（牌坊、叶片、栏杆）三条路线（poisson/2dgs/tsdf）都会出"开壳"；
   水密化与精修只让它"闭合"，不增加细节。
2. **LPIPS 与深度方差有取舍**：60k 下开深度方差要付 0.0046 LPIPS（G165）。
3. **峰值显存**：cap 600k + 每步 LPIPS 在 8GB 上已接近上限，长训练建议 cap ≤400k。
4. **`official` 密度控制**未标定，别开。
5. **质感指标（梯度/高频能量比）还没有阈值共识**，当前只用于相对比较。
