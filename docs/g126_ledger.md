## 11. 改动总账（训练框架到底改了多少、都改了什么）

> 统计口径：`git log --oneline -- src/gsflow/trainers/` = **32 次提交**；
> `config.DEFAULTS["train"]` = **62 个配置项**；
> `docs/03` 里与训练/质量相关的小节 = **34 条**（其中约 20 条是修 bug、约 8 条是负结果）。

### 11.1 按主题分组的**实质**改动

| 主题 | 改动 | 实测结论 | 依据 |
|---|---|---|---|
| **损失** | 掩码内均值 → 掩码外合成背景色、全图求损失 | 修掉"背景无监督 ⇒ 模糊/破碎" | G70 |
| | **`l1` 必须在替换 GT 之后算**（顺序 bug） | `composite` 曾对 L1 完全无效；掩码外亮度 0.904 → 0.005 | G123 |
| | **`bg_alpha_reg=0.1`**（掩码外 alpha 惩罚） | 掩码外 alpha 0.73 → **0.049**；掩码内 SSIM 反而升高 | G125 |
| | SSIM 常图偏置修正、高阶 SH 不再丢 | 两个真 bug 让我自己的测量失真 | G75 |
| | LPIPS（默认 0 = 关） | 3 重复下三指标均不显著、方差×3 | G79/G81 |
| **致密化** | `grad2d` 判据**真正生效**（孤儿 `elif` 曾覆盖它） | 同等质量下少 ~48% 高斯；降阈值到 1e-4 无收益 | G109/G117 |
| | grad2d 按 `W/2·nc`、`H/2·nc` **双轴**缩放 | 竖屏素材 y 梯度曾被低估 ~650 倍 | G109 |
| | `densify_until` 15000 → **4000** | 高斯少 68% 不退化；但**窗口后尺度无约束**，需配套 `max_scale_ratio` | G73/G125 |
| | `prune_scale3d`（尺度裁剪）补实现 | 漏掉它会让尺度无界增长 | G4 |
| **形状** | **`max_scale_ratio=0.05`**（每步限长） | `max_scale` 15.8 → **0.165**；针状权重 94.8% → 23.5% | G125 |
| | **`max_aspect`**（每步限长细比，本轮新增） | 针对"零厚度薄片"（实测最细 aniso 7509、smin 可到 0） | 本轮 |
| | `scale_reg` / `flatten_2dgs` | 2DGS 压平：法线场改善但 PSNR −1.15 dB ⇒ 默认关 | G67 |
| **不透明度** | 重置顺序红线（保存 → 评估 → 重置） | 否则最终检查点被重置污染、导出全黑 | G34 |
| | 重置默认关闭 + 三方案 A/B | 灾难来自**触发频率**，不是方案本身 | G84 |
| | `min_opacity_final` 收尾清理 | 清掉"看不见但占显存"的浮点 | 本册 §5.4 |
| **初始化** | 无相机轴翻转 + kNN 初始尺度 | 位姿约定错会让 PSNR 卡在 13~14 dB | G6 |
| **学习率** | 余弦退火 + 预热 | 与纯指数差异在噪声内；四元数 5e-4 更差 | G75 |
| **度量** | **`psnr_masked` / `ssim_masked`** 落地 | 掩码生效后全图指标失效（3.41 vs 20.84） | G123 |
| | 评估协议固定（视图数/迭代/分辨率） | 同一作业曾报 22.15 与 18.71 dB | G32 |
| **性能** | 分辨率只缩不放、渐进分辨率、`cap_max` | `resolution=1600` 在 720px 素材上会放大 2.2 倍 | G73 |

### 11.2 负结果（**测过但不采用**，这是同等重要的产出）

| 尝试 | 结果 |
|---|---|
| 抗锯齿光栅化（Mip-Splatting 思路）| −1.07 dB |
| AbsGS `absgrad` | 4 次重复 +0.098 dB，95% CI 跨 0 ⇒ 不显著 |
| `mask_loss_mode=inside` | 亮背景 61.2% → 59.6%，没解决目标问题 |
| `densify_until=15000` | 掩码内 SSIM 0.9093（更差）、高斯 4 倍 |
| 降低 grad2d 阈值到 1e-4 | 高斯 +89%，质量无提升 |
| 2DGS 压平 / 法线一致性正则 | PSNR −1.15 dB / 不收敛 |
| 高斯自带法线送泊松 | 3 个配置全部劣化 |

### 11.3 一句总结

训练框架的改动分三类：
1. **让配置真的生效**（grad2d、掩码损失、双轴缩放）—— 这类最贵，因为"配了但没执行"不会报错；
2. **加约束**（尺度上限、长细比、背景 alpha、尺度裁剪）—— 直接决定"看起来对不对"；
3. **改度量**（掩码内指标、评估协议）—— 决定"我们能不能看见问题"。

**质量提升主要来自第 1、2 类，而不是调超参。** 本轮之前所有"调参结论"都建立在
一个坏掉的度量上（G123），这也是为什么第 3 类必须先修。
