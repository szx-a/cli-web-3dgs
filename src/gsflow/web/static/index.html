3. 关键参数

8GB 显存建议：150~250 张图 / 长边 1400~1600 / 迭代 15000~30000。 实测：densify_until=4000 比官方默认 15000 更省（高斯少 68%） 且不会过训练退化；mask_loss_until=1.0（全程掩码约束）能让模型轮廓更干净、网格更准。

3.5 网格导出（可选，产物从"点云"变成"实体"）

网格流程：渲染深度 → 按不透明度/深度一致性过滤 → 反投影成稠密点云 → 体素下采样均匀化 → 泊松重建 → 平滑 → QEM 简化 → obj/ply/网格 glb → （可选）UV 展开 + 纹理烘焙。 mesh 会产出 model_mesh.obj / .ply / .glb； 开启纹理烘焙后额外产出 model_mesh_textured.glb（贴图内嵌）、 model_mesh_texture.png 与 model_mesh_uv.obj/.mtl。 网格 glb 可直接拖进 Blender、Unity、three.js 或 Windows「3D 查看器」。 实测轮廓 IoU：深度反投影路线 0.65，明显优于直接把高斯中心喂给泊松（0.24，网格只有物体的 1/5 大）。
