3. 关键参数

8GB 显存建议：150~250 张图 / 长边 1400~1600 / 迭代 15000~30000。 实测：densify_until=4000 比官方默认 15000 更省（高斯少 68%） 且不会过训练退化；mask_loss_until=1.0（全程掩码约束）能让模型轮廓更干净、网格更准。

3.5 网格导出（可选，产物从"点云"变成"实体"）

网格流程：渲染深度 → 按不透明度/深度一致性过滤 → 反投影成稠密点云 → 体素下采样均匀化 → 泊松重建 → 平滑 → QEM 简化 → obj/ply/网格 glb → （可选）UV 展开 + 纹理烘焙。 mesh 会产出 model_mesh.obj / .ply / .glb； 开启纹理烘焙后额外产出 model_mesh_textured.glb（贴图内嵌）、 model_mesh_texture.png 与 model_mesh_uv.obj/.mtl。 网格 glb 可直接拖进 Blender、Unity、three.js 或 Windows「3D 查看器」。 实测轮廓 IoU：深度反投影路线 0.65，明显优于直接把高斯中心喂给泊松（0.24，网格只有物体的 1/5 大）。

这套流程在做什么

      
    
        
  1. 抽帧/导入：视频经 ffmpeg 抽帧并缩放到目标长边，或直接导入图片。
    2. 
        
  2. AI 清理：分割后端生成前景掩码，背景填黑（或补全），同时输出掩码供 COLMAP 忽略动态物体。
          后端可选：classical（零依赖兜底）/ fastsam / rembg / sam2 / sam3（需 HF 授权）。
    3. 
        
  3. COLMAP：特征提取 → 匹配（自动判断序列/全局）→ 稀疏重建 → 导出，给出注册率与重投影误差体检。
    4. 
        
  4. 3DGS 训练：去畸变后用 gsplat 训练，自适应密度控制 + 渐进分辨率 + 掩码内损失。
    5. 
        
  5. 导出：PLY → GLB/SPZ/OBJ + 离线查看器 + 预览图。
    6. 
        
  6. 报告：注册率、掩码占比、清晰度、PSNR 与改进建议。
    7. 
      

      
架构红线

      
    
        
  • 流程核心不依赖 UI；CLI 与 Web 只是两个入口，行为完全一致（GUI 里会显示等价命令）。
    • 
        
  • 阶段之间只通过磁盘产物 + job.json 通信，随时可断点续跑或单阶段重跑。
    • 
        
  • 外部工具（ffmpeg/colmap）用适配器定位，缺失时给“可执行的修复建议”而不是堆栈。
    • 
      

      
显存建议（8GB 卡）

      
    
        
  • 1600px / 150~250 张 / 30k 迭代：可跑，训练约 30~60 分钟。
    • 
        
  • 大场景（>400 张或户外）：降到 1200~1400px，或分批重建后合并。
    • 
        
  • OOM 时流程会自动降一档分辨率重试一次。
