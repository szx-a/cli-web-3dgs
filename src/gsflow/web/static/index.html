3. 关键参数

拍摄模式决定**要不要保留背景**： orbit（相机绕行）抠背景是安全的；turntable（物体在转台上转、 相机与光源固定）**必须保留背景**——静态背景是"相机没动"的唯一证据， 抠掉会逼模型把"物体转"当成"相机转"，导致光照/遮挡不自洽、细节糊。 auto 按"背景帧间差异"判定（实测两类素材相差 34 倍）。

选择后会在下方「等价 CLI」里生成对应参数； 默认 none。实测（同数据 8000 迭代）：官方重置会让 PSNR 掉 0.59 dB，其余方案见 docs/03 G84。

8GB 显存建议：150~250 张图 / 长边 1400~1600 / 迭代 15000~30000。 实测：densify_until=4000 比官方默认 15000 更省（高斯少 68%） 且不会过训练退化。注意 resolution 只会缩小、不会放大： 若素材原生长边小于该值，会按原生尺寸训练（放大不增加信息、只会更慢）。

高级参数（任意配置项，每行 段.键=值）

界面上没有控件的配置项都可以在这里设置，例如： train.ssim_weight=0.2、train.eval_interval=2000、 train.white_background=false、train.pause_refine_after_reset=0、 export.mesh_normal_transfer_voxels=9。 # 开头为注释；这里填的键会覆盖上面的同名控件。

3.5 网格导出（可选，产物从"点云"变成"实体"）

网格流程：渲染深度 → 按不透明度/深度一致性过滤 → 反投影成稠密点云 → 体素下采样均匀化 → 泊松重建 → 平滑 → QEM 简化 → obj/ply/网格 glb → （可选）UV 展开 + 纹理烘焙。 mesh 会产出 model_mesh.obj / .ply / .glb； 开启纹理烘焙后额外产出 model_mesh_textured.glb（贴图内嵌）、 model_mesh_texture.png 与 model_mesh_uv.obj/.mtl。 网格 glb 可直接拖进 Blender、Unity、three.js 或 Windows「3D 查看器」。 实测轮廓 IoU：深度反投影路线 0.65，明显优于直接把高斯中心喂给泊松（0.24，网格只有物体的 1/5 大）。
